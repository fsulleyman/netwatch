Want live CPU %, disk and uptime for your own machine?

A website can't read those from your computer, but the same NetWatch app can run on it. On Windows, open PowerShell (Python and Git must be installed) and run: 

git clone https://github.com/fsulleyman/netwatch.git
cd netwatch
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python -m flask --app app.routes run --port 5000

Then open http://localhost:5000 — it will show that computer's real figures.
